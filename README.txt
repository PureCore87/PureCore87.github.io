Real Data. Clear Insight.

QUICK PREVIEW
Extract the ZIP and open index.html in a browser. Keep the assets folder
beside the HTML files. No PHP, server, JavaScript, database or build step
is required.

GITHUB PAGES
1. Create a public repository in GitHub, for example purecore-website.
2. Upload the extracted HTML files and the assets folder to the root of
   the repository. Upload the contents of this ZIP, not the ZIP itself.
3. Commit the files to the main branch.
4. Open Settings > Pages.
5. Under Source, select Deploy from a branch.
6. Select main and /(root), then Save.
7. Open the published website link displayed in the Pages settings.

Files use relative links, so a repository subpath works without changing
the code. The same files can also be uploaded to ordinary static hosting.

Header and footer markup are static and repeated in each page. Apply future
navigation changes to all seven pages.
