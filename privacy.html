This website.

This website contains no analytics, advertising scripts or code that sets cookies. Fonts come from your device; styles, scripts and artwork are served with the website. The ambient light animation runs locally in your browser and respects the reduced-motion preference.

The site is hosted on GitHub Pages. The hosting provider processes connection information needed to serve pages, such as IP addresses and request metadata. Hosting-related processing is separate from the website’s own code.

External links lead to services with their own privacy information. This page contains no contact form or server-side submission endpoint.

Signal / Network diagnostics

Local evaluation. Active network checks.

Signal reads and evaluates available technical Wi-Fi and mobile information on the device. The documented build has no required user account, advertising integration or behavioural analytics integration, and is not designed to record GPS movement history.

Network Check contacts 1.1.1.1 and may use a Cloudflare HTTPS endpoint. Target Check contacts your selected target and can involve a DNS resolver. Local discovery sends requests to local addresses and services. Recipients can receive technical metadata such as your public IP address and requested hostnames or URL components.

Android can require location, nearby-device and phone-state permissions for particular connection data. These permissions support technical diagnostics; their availability and requirements depend on Android and the device. Not every HTTP or local diagnostic connection is encrypted.

ARX Core / Local vault

Local storage. Deliberate sharing.

The documented ARX Core manifest has no internet permission. Its normal vault workflow does not require an ARX account, server or cloud service. Vault data is encrypted in private app storage; ordinary Android automatic app backup is disabled.

You can deliberately export readable files, open a selected file with another app, release credentials through Android Autofill or copy them to the system clipboard. A chosen document provider may use cloud storage for a backup or export. Information already read or copied by another app cannot be taken back by revoking later access.

ARX backups are encrypted and selected by you. Older backups retain their original passwords. The internal text viewer reads text locally, including an imported Logins.txt; exporting or sharing that file releases readable credentials.

This is a product data-flow overview of the documented development build. Release-specific app privacy information will be kept aligned with the final distribution.
