Network diagnostics

Signal.

What can I check?

Wi-Fi and mobile conditions, latency, jitter and available packet loss, specific domains/IPs/URLs, responding local devices, tested TCP ports, Wi-Fi channel conditions and possible repeater locations. The current app does not include a download/upload speed test.

Why are some values missing?

Android controls access to Wi-Fi and mobile measurements. Hardware, OS version, permissions, enabled services and the current network all affect availability. A missing value is not a measurement of zero.

Can checks use mobile data?

Yes. Active checks contact test targets or selected services and can use the active mobile connection. Their data use depends on the checks you run. Local discovery instead probes addresses in its local search range.

Why do local devices disappear when a VPN is active?

Discovery depends on routing, local reachability, VPN policies, firewalls and device responses. Signal contains VPN-related routing handling, but every VPN configuration is not guaranteed to work. Compare the same target and network conditions when reporting a problem.

Your private vault

ARX Core.

Which devices can use the development build?

The documented build requires Android 14 or later and compatible hardware-backed Keystore support. Android version alone is not sufficient to guarantee compatibility; device testing is continuing.

Can PureCore recover a forgotten vault password?

There is no developer key or reset that bypasses the encryption. Keep the correct password for the vault and each older backup. Losing the required information can permanently prevent access.

Why does an old backup reject my new password?

Older backups keep their original passwords. After changing the current master password, make a new backup and keep track of which password belongs to each existing backup.

What does an incomplete transfer mean?

ARX distinguishes the saved destination from the later removal of the source. A destination may have been verified while source removal could not be confirmed. Read the result and inspect the relevant locations before repeating a move.

Details that make an issue clearer.

When describing a problem, include the app and version, Android version, the action you took, the exact message and whether it happens consistently. For Signal, mention the connection type and whether a VPN is active.

Use sample data when possible. Do not include master passwords, backup passwords, credentials or private vault files in a support report.
